📘 SPÉCIFICATION FONCTIONNELLE — REVUE DE LITTÉRATURE, VARIABLES, WORKFLOW & EXPORTS

(Extension officielle du cahier des charges – Modules Fondements → Méthodologie)

1. Paramétrage — Variables fondamentales modifiables à tout moment
Principe général

Les paramètres définis lors de la création du projet (domaine, formation, discipline, type de travail, etc.) constituent les variables fondamentales utilisées par l’IA sur toute la plateforme.

👉 Ces variables sont :

visibles dans toutes les sections,

pré-sélectionnées par défaut,

modifiables à tout moment, section par section.

Listes déroulantes obligatoires (identiques au paramétrage initial)

Dans les sections :

Fondements (sujet / problématique / hypothèses)

Plan

Cadre conceptuel

Revue de littérature

Méthodologie

👉 Les mêmes listes déroulantes que dans le paramétrage initial doivent être disponibles :

Domaine

Filière

Discipline

Formation

Type de travail

Orientation (théorique / appliquée / mixte)

Option « Autre » (obligatoire partout)

Dans chaque liste déroulante, inclure :

option « Autre »

affichage automatique d’un champ texte libre

valeur saisie immédiatement utilisable par l’IA

Changement de variable & impact global

Lorsqu’une variable fondamentale est modifiée (ex. domaine, discipline, type de travail) :

👉 le système informe l’utilisateur :

« Cette modification peut impacter le sujet, la problématique, les hypothèses, le plan, les concepts, la revue de littérature et la méthodologie. »

L’utilisateur peut alors choisir :

☐ Réadapter automatiquement toutes les sections

☐ Réadapter seulement certaines sections

☐ Ne rien modifier pour l’instant
