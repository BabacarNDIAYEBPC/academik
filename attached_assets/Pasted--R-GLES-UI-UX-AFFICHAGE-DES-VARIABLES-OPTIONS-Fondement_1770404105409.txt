📘 RÈGLES UI / UX — AFFICHAGE DES VARIABLES & OPTIONS

(Fondement – Plan – Cadres – Revue – Méthodologie)

1. Principe général (OBLIGATOIRE)

Dans toutes les sections suivantes :

Fondement (sujet / problématique / hypothèses)

Plan

Cadre conceptuel

Cadre théorique

Revue de littérature

Méthodologie

👉 Les blocs “Variables utilisées” et “Options IA” ne doivent JAMAIS être affichés dépliés par défaut.

2. Comportement attendu par défaut

À l’arrivée dans une section :

Le contenu principal est affiché (résultat, plan, liste d’articles, etc.)

Les blocs suivants sont repliés :

Variables utilisées

Options de génération

Paramètres avancés

Boutons IA secondaires (changer, régénérer, affiner)

👉 L’interface reste propre, lisible, non intimidante.

3. Interaction utilisateur

L’utilisateur peut déplier volontairement :

les variables

les options

Une fois replié :

l’état reste mémorisé (préférence utilisateur)

Aucun champ ne s’ouvre sans action explicite de l’utilisateur

4. Cas spécifique — Revue de littérature

Dans la Revue de littérature :

Le formulaire de recherche est affiché

MAIS :

les options avancées

les filtres détaillés

les boutons d’analyse (mapping, confronter, analyser)

👉 sont repliés par défaut

L’utilisateur choisit quand il veut :

affiner

analyser

confronter

générer des visuels

5. Principe directeur UI

L’outil ne décide jamais à la place de l’utilisateur ce qu’il doit voir.
